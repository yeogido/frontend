# 데스크톱 UI 가이드

## 분기와 배율

뷰포트 폭이 1024px 이상이면 데스크톱 뷰를 사용하고, 그보다 작으면 기존 모바일 뷰를 사용합니다. 라우트 진입점에서 `Responsive`에 모바일과 데스크톱 컴포넌트를 전달합니다. `Responsive`는 데스크톱 트리에 `ScaleContext`를 제공하며, `useGlobalScale`은 이 값을 우선 사용합니다. 데스크톱 전용 컴포넌트는 시안의 픽셀 치수를 그대로 사용합니다.

## 새 화면 추가

1. `AppRouter`에 기존 모바일 뷰와 새 데스크톱 뷰를 `Responsive`로 연결합니다.
2. `src/constants/desktopRoutes.ts`의 경로 목록에 해당 라우트를 등록해 데스크톱에서 모바일 프레임 폭 제한을 해제합니다.
3. 상태, API 호출, 검증과 이동 로직은 공유 훅에 두고 화면별 마크업만 분리합니다.
4. `DesktopPageShell`을 사용하고, 공통 헤더와 푸터 또는 반복되는 레이아웃은 `src/components/layout/desktop`과 관련 공통 컴포넌트를 확장합니다.
5. 1023px과 1024px을 포함해 양쪽 화면 및 주요 상호작용을 확인합니다.
