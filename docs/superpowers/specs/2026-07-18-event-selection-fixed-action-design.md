# 행사 선택 바텀시트 고정 등록 버튼 설계

## 목표

행사 선택 바텀시트의 모든 스냅 높이에서 `행사 등록하기` 버튼을 항상 확인할 수 있게 하고, 선택된 행사 카드보다 위에 독립적으로 고정한다.

## 배치 구조

바텀시트 내부 순서를 다음과 같이 변경한다.

1. 드래그 손잡이
2. `추가된 행사` 헤더와 `전체 삭제` 버튼
3. 고정된 `행사 등록하기` 버튼
4. 빈 상태 문구 또는 독립적으로 스크롤되는 선택 행사 카드 목록

## 동작

- 등록 버튼은 30%, 60%, 90% 모든 스냅에서 고정 영역에 표시한다.
- 선택된 행사가 없을 때도 등록 버튼을 표시하되 비활성화한다.
- 선택된 행사가 없으면 등록 버튼 아래에 `아직 추가된 장소가 없어요` 문구를 표시한다.
- 선택된 행사가 있으면 등록 버튼을 활성화한다.
- 선택된 행사가 생기면 빈 상태 문구 대신 행사 카드 목록을 표시한다.
- 행사 카드 목록만 세로로 스크롤한다.
- 헤더, 전체 삭제 버튼, 등록 버튼은 목록 스크롤의 영향을 받지 않는다.
- 기존 바텀시트 스냅 및 드래그 동작은 변경하지 않는다.

## 구현 범위

- `DraggableBottomSheet`의 고정 액션 영역을 스크롤 목록 위로 이동한다.
- 호출부의 등록 버튼 활성화 조건과 스타일은 유지한다.
- Vaul 설정과 행사 선택 데이터 로직은 변경하지 않는다.

## 검증

- 초기 30% 스냅에서 비활성화된 등록 버튼과 `아직 추가된 장소가 없어요` 문구가 보인다.
- 행사를 추가하면 같은 위치에서 등록 버튼이 활성화된다.
- 목록이 길어져도 등록 버튼은 움직이지 않고 카드 영역만 스크롤된다.
- 60%, 90% 스냅에서도 동일한 내부 배치가 유지된다.
