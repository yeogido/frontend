# 지역 검색바 전국 필터 설계

## 목표

공통 `RegionImageCarousel`의 첫 칸에 이미지 없는 `전국` 필터를 제공한다.
기존 서울·부산 등 지역 항목은 두 번째 칸부터 현재 순서를 유지한다.

## UI

- 기준 크기: 기존 원형 카드와 동일한 64px
- 비선택 전국: `#A1A1A1` 배경, 흰색 14px Medium 텍스트
- 선택 전국: `#FF6F41` 배경, 흰색 14px Medium 텍스트
- 전국 항목에는 이미지·검은 오버레이를 렌더링하지 않는다.

## 데이터와 호환성

- 공통 옵션 타입은 이미지가 없는 전국 항목을 표현할 수 있도록 `imageSrc`를 선택 값으로 변경한다.
- 전국 ID는 공통 상수로 관리한다.
- 지역을 전체 조회할 수 있는 사용처만 전국 옵션을 전달한다. 지역 ID가 API 필수값인 화면은 기존 목록을 유지한다.

## 검증

- 전국이 첫 번째 항목으로 추가되는지 확인한다.
- 선택 상태별 배경색과 이미지 렌더링 여부를 단위 테스트로 검증한다.
- 기존 지역 항목의 선택·스크롤 동작은 유지한다.
